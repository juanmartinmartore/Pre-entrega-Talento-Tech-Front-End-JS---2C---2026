# Mi Sitio Web E-commerce

Este proyecto corresponde a una interfaz web de comercio electrónico desarrollada como parte de las actividades del programa **Talento Tech**. El sitio es completamente responsive y cuenta con una estructura moderna basada en HTML5 y CSS3.

## 📁 Estructura del Proyecto

Los archivos y recursos multimedia que conforman el repositorio están organizados de la siguiente manera:

```text
├── index.html           # Página principal del e-commerce
├── resenia.html         # Página secundaria de reseñas[cite: 5]
├── css/
│   └── style.css        # Hoja de estilos global
└── assets/
    └── img/
        ├── logo.png     # Logotipo principal de la marca[cite: 4]
        └── fondo.jpg    # Imagen de fondo para el contenedor principal[cite: 3]
